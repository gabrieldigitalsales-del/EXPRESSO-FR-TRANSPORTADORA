# Expresso FR — V14 Vite

Versão baseada no ZIP V9 enviado pelo usuário, mantendo o design aprovado e incorporando as alterações solicitadas.

## Rodar localmente
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Alterações principais
- novas imagens de caminhões com identidade Expresso FR integrada ao próprio veículo/lona;
- hero em carrossel a cada 3 segundos;
- preloader de 2 segundos;
- cotação em 4 etapas: responsável, coleta, destino e carga;
- coleta e destino com empresa, cidade e endereço;
- volumes, peso, medidas múltiplas, tipo de carga e urgência;
- WhatsApp comercial: (31) 97553-5768;
- revisão da cotação antes do envio;
- mobile reforçado para 720, 480, 390 e 340 px;
- faixa neon contínua;
- footer com copyright e crédito NEXOR DIGITAL linkado ao Instagram.
